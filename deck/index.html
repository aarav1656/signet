The chain records which code traded.

The strategy text is sealed config in the enclave and the measured compose pins its SHA-256. What reaches the chain is the code's measurement, the model's hash and a hash of each request and response.

  1. enclave

    Intel TDX CVM

    The agent generates its trading key here and runs its decision loop here. The strategy text is sealed config.

  2. quote

    Attestation

    Commits to the key and to a nonce from the last 256 L2 blocks. It cannot be banked in advance.

  3. Stylus Verifier

    Intel's root

    Walks the certificate chain, rejects debug mode, returns a measurement over nine TD fields.

  4. AgentAccount

    Follower approves

    Stores the key only if the follower approved that exact measurement.

  5. TradeExecuted

    Receipt names it

    Measurement, served model hash, request hash, response hash, amounts.

Followers approve one measurement. Limits sit underneath.

Following is a call on the follower's own account. Funds never leave it, and the account, not the agent, calls the Uniswap v4 PoolManager.

Follower's accountenforced in the swap transaction

  1. Approve a measurement

    setMeasurement(hash, true), after unapproving every other measurement on the account. The agent is admitted only against a fresh quote that carries it.

  2. Set the caps

    setLimits: per-trade, rolling 24 hours, and an approval threshold. Bigger trades wait for the owner.

  3. Settle by balance delta

    The swap reverts unless the account spent no more than amountIn and received at least minOut.

  4. Unapprove and the agent is out

    Same transaction, AgentRevoked. The next trade reverts NotAgent.
